## 7. Extension Popup Menu

- **Two-column layout** (v3.0.0 redesign): The popup uses a side-by-side two-column flex layout (`body` width 660px). The left column from top to bottom: title bar card (title + master toggle), Global Prompt card ("Global Prompt" label + pencil edit button + dedicated injection toggle), Prompt Group card (prompt group selector + `+` button + pencil edit button), **Features card** (inject system time, collapse thinking process, auto-expand messages, prevent auto-scroll, web search). The right column includes the Export card (export-related features and language switcher), **Backup & Restore card** (with five action buttons: `#exportJsonBtn` export settings, `#importJsonBtn` import settings, `#exportRestoredBtn` export restored backup, `#importRestoredBtn` import restored backup, `#clearRestoredBtn` clear all restored records), and the UI Adjustments card (sidebar auto-hide, conversation area width, input box width).
- **Prompt group selector**: A custom combobox component (`role="combobox"`) for selecting the active prompt group. The trigger flexibly fills the remaining width between the label and the buttons on the right; overlong names are truncated with an ellipsis. The expanded panel contains a search input for real-time filtering of prompt groups (panel width still spans the full control area row). Each prompt group item has a drag handle on the left for drag-to-reorder; on mouse hover, the right side shows pin and delete (`✕`) icon buttons (v4.14.0 removed the in-row rename pencil — renaming moved to the editor window; v4.18.0 added the pin button to the left of `✕`). The pin represents "default prompt group" — a pinned item lights up with `var(--primary-color)` and is unaffected by hover enter/leave (row buttons use `visibility` for show/hide toggling, with the layout box always present); unpinned pins only appear on row hover. The icon is a `viewBox="0 0 20 20"` solid inline SVG (`fill="currentColor"`, 12×12, visually matching the `✕` glyph size in the same row). To the right of the dropdown, in order, are the add (`+`) button and pencil edit button. The pencil button's right edge aligns with the card content's right edge (on the same vertical line as toggles in other cards); the spacing between the dropdown and buttons and between the two buttons is identical (2px).
- **Pencil edit buttons** (v3.0.0): Two pencil buttons (global prompt `#editGlobalPromptBtn`, prompt group `#editPresetBtn`) reuse the `.icon-btn` style (26×26, border-radius 4px, white background). The icon is an inline SVG pencil (shaft from upper-right to lower-left). Clicking opens the corresponding target's standalone editor window (see "Standalone Prompt Editor Window"). The prompt group pencil is disabled when the blank option is selected.
- **Global prompt toggle** (v3.0.0, changed to per-prompt-group independent v4.20.0): `#globalPromptToggle` at the right edge of the Global Prompt card, same appearance as the master toggle, controls `globalPromptEnabled`. As of v4.20.0, the read/write target depends on whether an active prompt group exists: if yes, it reads/writes that group's `globalPromptEnabled` field (also updating its `updatedAt`); if no, it uses the device-level legacy key. The toggle state is re-rendered when the popup opens, when switching prompt groups, and when deleting a prompt group causes `activePresetId` to be cleared (`popup/popup.toggles.js`'s `renderGlobalPromptToggle()`). No new UI elements were added.
- **Sync status indicator** (v2.0.0): The `#syncStatus` element next to "Saved" in the title bar. Displays green "Cloud Synced" or red "Not Synced" depending on whether `dsLocalAuth` is empty. Updated after each save operation.
- **Language switcher** (v4.3.3): A globe icon button (`#localeSwitcherBtn`) in the Export card. Clicking shows the language panel (`#localePanel`) to switch between Traditional Chinese (zh_TW) and English (en). Implemented in `popup/popup.locale.js`, using `utils/i18n.js`'s `dsI18n.setLocale()` for switching; the popup reloads after switching.
- **Enable/disable toggle (master toggle)**: Controls whether prompt injection is enabled. When off, all sub-controls (sidebar auto-hide, collapse thinking process, auto-expand messages, prevent auto-scroll, web search, inject system time, conversation area width, input box width) are disabled via the `disabled` attribute.
- **Thinking process toggle**: A checkbox controlling whether exported Markdown includes AI thinking process.
- **Reference links toggle**: A checkbox controlling whether exported Markdown includes citation reference links.
- **System time toggle**: A checkbox controlling whether current time is auto-injected at the beginning of each message.
- **Export button**: A button that triggers Markdown export on the active `chat.deepseek.com` tab.
- **State persistence**: All settings must be stored in `chrome.storage.sync` (with local fallback).
- **Auto-save**: Settings are auto-saved on change, with a brief green "Saved" text indicator next to the title.
- **Custom dialog system**: All dialogs (add prompt group, delete confirmation, error alerts) use an inline dialog controller (`Modal`) that renders a vertically centered overlay within the popup, replacing the browser's native `prompt()`/`confirm()`/`alert()`. (As of v4.14.0, renaming no longer uses `Modal.prompt` but is done in the editor window's name input field.)

## 15. In-Page Overlay Prompt Group Switching

- **Position and style**: An absolutely positioned dropdown is displayed at the center of the DeepSeek conversation page's top header bar (`div._2be88ba`), overlaying the header bar (`z-index: 1000`). The dropdown uses a dark semi-transparent background (`rgba(0,0,0,0.45)`), white text, rounded borders, and a maximum width of 200px.
- **Mobile positioning** (v4.2.2): On mobile (viewport < 768px), the overlay uses gap positioning mode, placed between the DeepSeek new conversation/share buttons (inside `._1aa2651`) and the conversation title. Since these buttons render with a delay on page load (position shifts left before the layout settles), the overlay is equipped with a bounded settle retry loop: it continuously measures the button's `left` position frame-by-frame until it stabilizes for K consecutive frames (convergence) or reaches the maximum frame count, ensuring accurate final positioning. Desktop mode (>= 768px) centering is unaffected.
- **Activation timing**: Automatically activated during Content Script initialization (`initSettings()`), requiring no additional user action.
- **Bidirectional sync**:
  - Overlay selection change → writes to `activePresetId` and `chatPresetMap` → popup reflects the change on next open.
  - Popup change → `ACTIVE_PRESET_CHANGED` message → overlay updates selected value in real time.
  - Prompt group list changes (add/delete/rename) → `storage.onChanged` → overlay re-renders the option list.
- **Conversation binding support**: Selecting a prompt group via the overlay on a conversation with a UUID also updates the `chatPresetMap` binding. Selecting the blank option unbinds.
- **SPA navigation resilience**: A `MutationObserver` monitors DOM changes. When a conversation switch causes the header bar to be rebuilt, the overlay is automatically remounted with the correct binding state restored.
- **No-UUID handling**: On new conversation pages (no UUID), the overlay's selection writes to `pendingPresetId`, handled by the Content Script's existing auto-binding mechanism on first send.
